opsward.decisions#

Decision capture: numbered ADRs, the one-line decision log, and their drift.

Two tiers, per ADR 0010 and misc/docs/research/adr_and_home_finding.md: a trivial or medium decision is one Y-statement line appended to decisions/log.md (“In the context of …, facing …, we decided for …, to achieve …, accepting …, because …”); a load-bearing, expensive-to-reverse one is a numbered MADR file decisions/NNNN-slug.md that is never edited once accepted, only superseded.

Pure functions here; the CLI (opsward decision new|note) is the only writer, and it never overwrites. maintain uses check_decisions() to report an ADR that cites a path which no longer exists, or that has no Status, which is how rot shows up.

opsward.decisions.check_decisions(sr)[source]#

maintain check: ADRs citing paths that no longer exist, or carrying no status.

Rot in a decision record is a path that moved: the rationale still reads well and points at nothing. Superseded, deprecated and rejected ADRs are history and are not checked for paths: the superseding record is where the current paths live. This reports; it never rewrites an accepted ADR (ADR 0010).

Return type:

Iterable[MaintenanceSuggestion]

opsward.decisions.cited_paths(content)[source]#

Paths an ADR cites as current, outside fenced code: bare path tokens and Markdown link targets (relative ones only; URLs and host names are not paths).

A path the record cites as history is not checked: wrap it in ~~strikethrough~~, or say so on the line (formerly, previously, moved, migrated, renamed, replaced, removed, retired, deleted), as in “we moved pkg/old.py to pkg/new.py” — there only pkg/new.py must exist.

>>> cited_paths("See `pkg/a.py`, [0002](0002-x.md), [doc](../research/r.md), https://x.io/a/b.py, docs.github.com/en/x.md\n```\nsrc/in/fence.py\n```")
['../research/r.md', '0002-x.md', 'pkg/a.py']
>>> cited_paths("We moved `pkg/old.py` to `pkg/new.py`; ~~`pkg/gone.py`~~ is history.")
['pkg/new.py']
>>> cited_paths("It was read from `pkg/live.py`.\nRenamed [old](../old.md) to [new](../new.md).")
['../new.md', 'pkg/live.py']
Return type:

list[str]

opsward.decisions.log_append(decisions_dir, text, *, date=None)[source]#

The log file and the full content it should hold after appending text.

A missing log starts from the log.md template. The existing log is read strictly: an unreadable or non-UTF-8 log raises (OSError / UnicodeDecodeError) rather than being replaced by the new line alone. The caller writes; this does not.

opsward.decisions.new_adr(decisions_dir, title, *, status='Proposed', date=None, evidence='')[source]#

The next numbered ADR for title, rendered from the adr.md template.

evidence is the issue, discussion or PR the decision rests on (a URL or #N); it lands in the Evidence section so the three surfaces stay linked.

>>> import tempfile
>>> gf = new_adr(Path(tempfile.mkdtemp()), "Pin the CLI surface", date=_dt.date(2026, 10, 19), evidence="#8")
>>> gf.target_path.name, gf.content.splitlines()[0]
('0001-pin-the-cli-surface.md', '# 0001 — Pin the CLI surface')

opsward.decisions.status_of(content)[source]#

The ADR’s status text, from a ## Status heading, a **Status:** line or MADR front matter; None when there is none.

>>> status_of("# x\n\n## Status\n\nAccepted (2026-01-01)\n")
