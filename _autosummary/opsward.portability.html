opsward.portability#

Multi-host portability: which agent hosts a repo satisfies, and canonical↔render drift.

The canonical project brief is AGENTS.md (opsward#15). Every other host’s instruction file (CLAUDE.md, GEMINI.md, .github/copilot-instructions.md, …) is a render of it, related to it in one of three ways:

  • symlink — the file is a symlink to AGENTS.md: byte-identical, cannot drift;

  • import — the file imports it (@AGENTS.md) and adds host-only deltas: the recommended shape for hosts with an import syntax (Claude Code, Gemini CLI);

  • copy — a separate file: everything in it can drift from the canonical.

The check is a linter: the canonical is authoritative and drift in a render is reported, never merged back. Three finding kinds, matched section by section (by normalised heading):

  • stale — a canonical section is missing from a copy;

  • diverged — a section is in both, with different bodies (a stale render or a hand edit in the render: the files alone cannot say which);

  • host_only — a section only the render has: promote it to AGENTS.md if it is portable, or keep it as a host delta (after an @AGENTS.md import).

Scoped-rule folders (.cursor/rules/, .windsurf/rules/, .clinerules/) count towards coverage but are not compared: they are not renders of one brief.

A fourth kind, lossy, is about skills rather than the brief: a project skill rendered for a host whose format drops some of its fields (allowed-tools, license, bundled resources). Where each host installs skills and what its format drops is the skill package’s registry (skill.install.agent_targets, skill.translate.lost_fields); HostSpec.skill_target points into it, so the two registries are joined, not copied. check_portability reports it when skill is installed (pip install 'opsward[lint]'); it is never scored.

Files that are only coverage signals (CONVENTIONS.md is often a contributor doc, not a render) are compared only when they import or link the canonical.

read_host_files is read-only (it backs scan); analyze is pure.

>>> report = analyze(
...     "# P\n\n## Build\n\npytest\n",
...     {"CLAUDE.md": HostFile("CLAUDE.md", "## Build\n\npytest -x\n## Claude\n\nx\n")},
... )
>>> report.coverage["claude"], report.coverage["codex"]
('copy', 'native')
>>> sorted((f.kind, f.section) for f in report.findings)
[('diverged', 'build'), ('host_only', 'claude')]

opsward.portability.as_read(render, canonical)[source]#

render as its host reads it: an @AGENTS.md import replaced by canonical.

A line that is only the import is replaced in place; an import inside a sentence appends the canonical at the end. A copy (no import) comes back unchanged, so scoring a shim judges what the agent actually sees, not the three-line file.

>>> as_read("@AGENTS.md\n\n## Claude\n\nx", "## Build\n\npytest\n")
'## Build\n\npytest\n\n## Claude\n\nx'
>>> as_read("Read @AGENTS.md first.", "## Build")
'Read @AGENTS.md first.\n\n## Build'
>>> as_read("## Build\n\npytest", "## Other")
'## Build\n\npytest'
